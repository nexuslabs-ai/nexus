# Examples

Four real apps show nxds added to a new app, a shadcn app, an MUI app and a
company design-system package.

## Pick the example closest to your app

| Your app                                 | Example                                                                                    | Where nxds lives                        |
| ---------------------------------------- | ------------------------------------------------------------------------------------------ | --------------------------------------- |
| A new Next.js app                        | [`nxds-app`](https://github.com/nexuslabs-ai/nxds/tree/main/examples/nxds-app)             | The app                                 |
| A Next.js app built with shadcn/ui       | [`shadcn-app`](https://github.com/nexuslabs-ai/nxds/tree/main/examples/shadcn-app)         | Beside `components/ui`                  |
| A shadcn-based design-system package     | [`shadcn-package`](https://github.com/nexuslabs-ai/nxds/tree/main/examples/shadcn-package) | In the package, or in the app beside it |
| A Vite app with Material UI, no Tailwind | [`mui-app`](https://github.com/nexuslabs-ai/nxds/tree/main/examples/mui-app)               | The app                                 |

Adding nxds changes none of the host app's own styles in any example.

## What each example shows

| Setup step                                  | Where to look                       |
| ------------------------------------------- | ----------------------------------- |
| A separate nxds CSS entry beside yours      | `shadcn-app/app/nxds.css`           |
| One theme switch for both systems (`.dark`) | The header of every coexistence app |
| Toasts from each system stay separate       | The `/overlays` page                |
| nxds overlays above MUI's layers            | `mui-app/src/nxds.css`              |
| MUI popups inside an nxds dialog            | The `mui-app` `/overlays` page      |
| A package that ships nxds (`@source './'`)  | `shadcn-package/ui`                 |

## Run an example

```bash
git clone https://github.com/nexuslabs-ai/nxds
cd nxds/examples/shadcn-app
npm ci
npm run build
npm start
```

Each example's README lists its pages and how it added nxds.
