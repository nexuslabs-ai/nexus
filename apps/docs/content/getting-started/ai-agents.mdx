# AI agents

Point your AI agent at `/llms.txt` to give it every Nexus docs page as Markdown.

## Fetch the index

```bash
curl https://nxds.dev/llms.txt
```

`/llms.txt` lists every docs page, by section. Each entry links to the page's
Markdown and gives a one-line summary.

## Read one page as Markdown

Add `.md` to the URL of any page in `/llms.txt` to get that page as Markdown.

```bash
curl https://nxds.dev/getting-started/install.md
```

The Markdown keeps the page's text, tables and code. Live previews and copy
buttons are left out, because they mean nothing as text.

## Fetch every page in one file

```bash
curl https://nxds.dev/llms-full.txt
```

`/llms-full.txt` holds the Markdown of every docs page, in nav order. It is about
2 MB, because it includes every code example. If your agent should pick pages
itself, use `/llms.txt`.
