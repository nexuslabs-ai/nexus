# Theme setup

Set your app's starting theme, and keep the user's choices across reloads.

Start here after [Install](/getting-started/install).

## Set your default theme

Copy the default appearance and change the fields you want:

```ts
// app/appearance-state.ts (Next.js) or src/appearance-state.ts (Vite)
import {
  DEFAULT_NEXUS_APPEARANCE,
  type NexusAppearanceState,
} from '@nexus_ds/core';

export const defaultAppearance = {
  ...DEFAULT_NEXUS_APPEARANCE,
  brandColor: '#2563eb',
  surfaceTone: 'slate',
} satisfies NexusAppearanceState;
```

`brandColor` sets the primary color. `surfaceTone` sets the gray used for
backgrounds: `stone`, `neutral`, `zinc`, `slate` or `gray`. For every field,
see [Appearance](/theming/appearance).

Then follow the section for your framework.

## Next.js

Replace the layout from Install with this one. It reads the user's saved
theme from a cookie, so the server renders the right theme on the first
request:

```tsx
// app/layout.tsx
import {
  createNexusAppearanceSnapshotFromCookie,
  DEFAULT_COOKIE_KEY,
} from '@nexus_ds/core';
import { cookies } from 'next/headers';

import { NexusAppearanceProvider } from '@/components/appearance/provider';
import { NexusAppearanceScript } from '@/components/appearance/provider/server';

import { defaultAppearance } from './appearance-state';

import './globals.css';

export default async function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  const cookieStore = await cookies();
  const snapshot = createNexusAppearanceSnapshotFromCookie(
    cookieStore.get(DEFAULT_COOKIE_KEY)?.value,
    defaultAppearance
  );

  return (
    <html lang="en" suppressHydrationWarning>
      <head>
        <NexusAppearanceScript
          storageKey="app-appearance"
          defaultState={snapshot.state}
        />
      </head>
      <body className="nx:bg-background nx:text-foreground nx:typography-body-default">
        <NexusAppearanceProvider
          storageKey="app-appearance"
          cookieWriteKey={DEFAULT_COOKIE_KEY}
          defaultState={snapshot.state}
        >
          {children}
        </NexusAppearanceProvider>
      </body>
    </html>
  );
}
```

If the cookie is missing or invalid, `createNexusAppearanceSnapshotFromCookie`
falls back to `defaultAppearance`.

The provider saves the theme in two places:

| Prop             | Saves to       | Read by                                               |
| ---------------- | -------------- | ----------------------------------------------------- |
| `cookieWriteKey` | A cookie       | The server, on the next request                       |
| `storageKey`     | `localStorage` | The head script before first paint, then the provider |

When both are set, `localStorage` wins in the browser. To use only the cookie,
set `storageKey={false}` on both the script and the provider.

If your app uses a strict Content Security Policy, pass a nonce:
`<NexusAppearanceScript nonce={nonce} />`.

## Vite

Vite doesn't render on the server, so add the theme script to `index.html` at
build time:

```ts
// vite.config.ts
import {
  createNexusAppearanceBootstrapScript,
  createNexusAppearanceSnapshotFromState,
} from '@nexus_ds/core';
import react from '@vitejs/plugin-react';
import { defineConfig } from 'vite';

import { defaultAppearance } from './src/appearance-state';

const STORAGE_KEY = 'app-appearance';
const defaultSnapshot =
  createNexusAppearanceSnapshotFromState(defaultAppearance);

export default defineConfig({
  plugins: [
    react(),
    {
      name: 'nexus-appearance-bootstrap',
      transformIndexHtml(html) {
        const script = createNexusAppearanceBootstrapScript({
          storageKey: STORAGE_KEY,
          defaultSnapshot,
        });
        return html.replace('</head>', `<script>${script}</script></head>`);
      },
    },
  ],
});
```

On Vite, copy the provider into `src/components/appearance/provider/`. Then wrap
your app in the provider, with the same storage key:

```tsx
// src/main.tsx
import { createRoot } from 'react-dom/client';

import App from './App';
import { defaultAppearance } from './appearance-state';
import { createNexusAppearance } from './components/appearance/provider';

import './index.css';

const { NexusAppearanceProvider } = createNexusAppearance({
  storageKey: 'app-appearance',
  defaultState: defaultAppearance,
});

createRoot(document.getElementById('root')!).render(
  <NexusAppearanceProvider>
    <App />
  </NexusAppearanceProvider>
);
```

Don't apply the theme in a `useEffect`. Effects run after the first paint, so
the page would flash the default theme first.

## Check your setup

- [ ] `nexus.css` is imported from your CSS entry point
- [ ] The provider wraps your app, and the script is in `<head>`
- [ ] Reloading in dark mode doesn't flash light first
- [ ] The mode you pick is still set after a full reload

If the page still flashes, check that the script and the provider use the
same `storageKey`. With different keys, they load different themes.
