Add density-independent 12/14/16px icon-size primitives (`--nx-icon-glyph-xs`, `--nx-icon-glyph-sm`, `--nx-icon-glyph-default`) with matching `size-icon-glyph-*` utilities, and a 13px `xs-plus` type-size primitive used by the new `typography-label-compact` style, to support the Button and ButtonGroup size scale. Shared spacing-density values are unchanged.
