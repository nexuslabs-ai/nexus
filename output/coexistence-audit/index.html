Coexistence audit — verified findings

19 October 2026 · Local Nexus source · MUI 9.5.0 · Ant 6.6.6 · installed shadcn radix-nova styling with published 4.22.1 variant helpers.

No evidence of broad MUI or Ant component destruction. The strongest differences are global stylesheet integration effects. These are conditional on importing the tested unscoped Tailwind/shadcn globals after existing styles, not unavoidable defects in individual shadcn components.

Where Nexus preserved the existing UI

Existing UI shadcn integration result Nexus integration result Condition / mechanism
Custom branded button and card Teal changes to neutral; radius changes from 16px to 10px. Existing brand variables and radius preserved. Existing app deliberately uses generic --primary, --primary-foreground, --radius. Later shadcn :root/.dark declarations reuse these names. This is a representative token-name collision, not a default MUI/Ant token collision.
Native form inside MUI host Input/button/select backgrounds become transparent; borders disappear; font and dimensions change. Light-mode baseline preserved. Dark provider changes browser-native colors but preserves structure. Tailwind Preflight global form reset. Not reproduced as breakage of styled MUI TextField or Ant Input.
Native navigation links Underlines removed; color inherits. Underline preserved. Dark color-scheme changes native link color. Global anchor reset.
Native headings and lists Heading 24px → 16px; ordered-list numbering removed. Structure preserved. Global heading/list reset, already known.
Native HTML table Spacing and height change. Preserved. Preflight border-collapse/padding reset. This is not an Ant or MUI DataGrid failure.

Excluded from a Nexus superiority demo

  • Body-portaled searchable selector under MUI Dialog or Ant Modal: both kits fall below the host modal with default stacking levels.
  • Ant reset overriding text-color utilities on added primary buttons/checkboxes: both kits affected in the neutral-theme test.
  • Computed border changes with zero border width, and hidden-input font/color changes: not counted as visible failures.
  • Transient border-width measurements were removed by waiting for CSS transitions before both samples.

Coverage limits

This is not a completed runtime certification of every component and exported subpart. Source inventory covers 79 Nexus source modules and 24 installed shadcn modules, plus 64 of 65 upstream registry UI entries retrieved (toast unavailable in this preset). Unexercised components are explicitly marked in the coverage file. Hover, focus, responsive sizes, portal nesting and all permutations are not exhaustively runtime-tested. Upstream current Combobox uses Base UI; the exercised installed shadcn searchable selector uses Popover + input + cmdk.

The theme-token fixture intentionally models an app with overlapping variable names. It does not establish that an unmodified MUI or Ant theme has those names. Existing Tailwind apps that already use Preflight will not experience a newly introduced Preflight reset in the same way.
